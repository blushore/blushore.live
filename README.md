# blushore.live

The Blu Shore website. Plain HTML, CSS and JS with no build step, hosted on GitHub Pages at https://blushore.live.

- **Make a change from any device:** open this repo in [claude.ai/code](https://claude.ai/code) and ask, or edit on github.com. Pushing to `main` goes live in about a minute.
- **Preview locally:** run `python3 -m http.server 4173`, then open http://127.0.0.1:4173.
- **New music:** run `python3 tools/update-releases.py`.

Full details on structure, design rules and hosting are in [CLAUDE.md](CLAUDE.md).
